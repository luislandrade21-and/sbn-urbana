# SBN nas cidades brasileiras · Guia de estudo da ENSBN-Urbana

Guia interativo da Estratégia Nacional de Soluções Baseadas na Natureza para Áreas Urbanas (ENSBN-Urbana), publicada pelo Ministério do Meio Ambiente e Mudança do Clima em 2026.

**Site:** https://sbnurbana.netlify.app

> Material de estudo. Para citar, use sempre o PDF original do MMA.

## O que cobre

| Parte | Capítulos |
|---|---|
| 1 A ideia | O problema · O que é uma SBN · Tipos de intervenção · A escala · Para quem |
| 2 O programa | Governança · Metas até 2035 · Plano de Ação · Monitoramento |
| 3 Pôr em prática | Avaliar um projeto · Avaliar um plano · O que fica em aberto |
| Anexo | Fontes: siglas, legislação e mapa do PDF |

## Estrutura

Um único ficheiro, `index.html`, com textos, estilos, ícones e lógica. Não há dependências nem compilação: para ver localmente, basta abrir o `index.html` no browser.

## Publicação

O site está no **Netlify**, ligado a este repositório: cada push para `main` publica a nova versão em cerca de um minuto.
